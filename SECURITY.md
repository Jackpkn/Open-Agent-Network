## 🚨 Reporting a Vulnerability

**Please DO NOT report security vulnerabilities through public GitHub issues.**

Instead, please report security issues directly to our security team via email at:

📧 **`security@open-agent-network.org`**

### What to Include in Your Report:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC) script.
- Potential impact (e.g., unauthorized escrow release, reentrancy risk, key exposure).
- Any suggested fixes or mitigations.

### Disclosure Timeline:
- **Acknowledgement**: Within 24 hours.
- **Initial Assessment**: Within 48 hours.
- **Fix & Patch Release**: Within 7 business days for high-severity vulnerabilities.

Thank you for helping keep the Open Agent Network secure!
